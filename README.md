# Nikandrov-Frontend-NAD-Labs-2026

Витрина малых модульных реакторов (СМР) — SPA на React 19 + TypeScript + Vite с маршрутизацией `react-router-dom`. Все данные приходят из моков ([app/src/mocks/smrs.tsx](app/src/mocks/smrs.tsx)), тип сущности — [`Smr`](app/src/types/smr.tsx).

Приложение состоит из **двух страниц**:

| Маршрут | Страница | Файл |
|---|---|---|
| `/` | Плитка с фильтром и списком карточек | [app/src/pages/SmrGridPage.tsx](app/src/pages/SmrGridPage.tsx) |
| `/smr/:id` | Детальная страница реактора | [app/src/pages/SmrDetailsPage.tsx](app/src/pages/SmrDetailsPage.tsx) |

Роуты объявлены в [app/src/main.tsx](app/src/main.tsx). Обе страницы обёрнуты в [`Layout`](app/src/components/layout/Layout.tsx) (шапка + подвал).

Запуск: `cd app && npm install && npm run dev`.

## Страница 1. Плитка — `/`

Файл: [app/src/pages/SmrGridPage.tsx](app/src/pages/SmrGridPage.tsx)

Заголовок раздела — «МАЛЫЕ МОДУЛЬНЫЕ РЕАКТОРЫ», ниже сетка из фильтра и карточек СМР.

### Фильтр «Тепловая мощность, МВт»

Компонент: [app/src/components/smr/SmrFilter.tsx](app/src/components/smr/SmrFilter.tsx)

| Элемент | Тип | Поля / параметры | Поведение |
|---|---|---|---|
| Счётчик диапазона | текст `От {min} до {max}` | значения по умолчанию: `min = 100`, `max = 500` | обновляется при движении ползунков |
| Ползунки «От» и «До» | `input[type=range]` | имена `thermal_power_min` (100–240, шаг 10) и `thermal_power_max` (260–500, шаг 10) | задают границы тепловой мощности |
| Кнопка «Найти» | `input[type=submit]` | — | отправляет форму (`onSubmit({ thermal_power_min, thermal_power_max })`, предотвращается перезагрузка страницы). На странице плитки компонент вызван без `onSubmit`, поэтому фильтрация списка пока не применяется |

### Карточка реактора

Компонент: [app/src/components/smr/SmrCard.tsx](app/src/components/smr/SmrCard.tsx) — рендерится для каждого элемента из `MOCK_SMRS`.

| Элемент | Тип | Описание |
|---|---|---|
| Карточка целиком | ссылка `Link` на `/smr/{id}` | клик открывает детальную страницу реактора |
| Изображение | `img` | `image_url` из данных, иначе дефолт `/images/default_smr.png` |
| Производитель и название | текст (`РОСАТОМ`, `РИТМ-200` и т.д.) | данные из объекта `Smr` |
| Лайки | SVG-сердечко + число | счётчик лайков из `MOCK_LIKES` (только отображение) |
| Кнопка «Удалить» | `button[type=submit]` внутри формы | появляется, только если передан проп `onDelete`; на странице плитки он не передаётся, поэтому кнопка сейчас не отображается |

## Страница 2. Карточка реактора — `/smr/:id`

Файл: [app/src/pages/SmrDetailsPage.tsx](app/src/pages/SmrDetailsPage.tsx)

Полноэкранная страница реактора: фоновое зацикленное видео (`video_url` из данных, иначе `/videos/default_smr.mp4`, режимы `autoPlay / muted / loop / playsInline`) и оверлей поверх него.

### Поля данных (только отображение, полей ввода нет)

| Поле | Разметка | Пример |
|---|---|---|
| Название реактора | `h1` | РИТМ-200 |
| Производитель | `h1` | РОСАТОМ |
| Тепловая мощность | `h2` | «Тепловая мощность: 190 МВт» |
| Электрическая мощность | `h2` | «Электрическая мощность: 50 МВт» |
| Описание | `h2` в блоке `product-description` | обрезается до 29 символов + `...`, полный текст — при раскрытии |

### Кнопки

| Кнопка | Тип элемента | Поведение |
|---|---|---|
| Лайк (сердечко) | `button.like.action-btn` со SVG | переключает лайк: при первом нажатии ставит лайк (+1 к счётчику, сердечко становится красным — класс `active`), при повторном снимает (−1). Локальный стейт, сбрасывается при перезагрузке |
| «Далее» (иконка play) | `Link.next.action-btn` на `/smr/{id}?next=true` | открывает следующий режим просмотра той же карточки |
| «Еще» | `button.more` | раскрывает/сворачивает полное описание реактора |

### Состояние «реактор не найден»

Если `id` не найден в моках, вместо карточки показываются заголовок «Реактор не найден».
